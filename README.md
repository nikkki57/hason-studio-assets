# Hason Studio — public assets

Files that have to be reachable from anywhere, such as the logo in email
signatures. Mail apps load signature images from a public address, and the
main website repository is private.

- `email-logo.png` — signature logo, 440×91, displayed at 220×46.

If the logo ever changes, add it under a new filename rather than replacing
this one: mail apps cache images, and emails already sent keep loading this path.
